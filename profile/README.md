## Overview

Sejda PDF Editor is a PDF editing platform concept built around text editing, form handling, and document conversion. It brings together font detection, OCR, signatures, and page management into both browser-based and offline desktop environments .

## Essential Sejda PDF Editor Features

- **Text Editing with Font Detection:** Modify existing PDF text while preserving the original typography through automatic font detection .
- **Form Filling and Signatures:** Complete interactive forms and add signatures by drawing, typing, or uploading an image .
- **OCR for Scanned Documents:** Extract text from scanned PDFs and images to make them searchable and editable .
- **Page Management:** Merge, split, delete, rotate, and extract pages from PDF documents .
- **Conversion Tools:** Convert PDFs to Word, Excel, PowerPoint, JPG, and text formats, and convert other files to PDF .

## What Sejda PDF Editor Brings to PDF Workflows

The platform provides both web and desktop environments for PDF tasks. Its structure supports quick browser-based edits and offline processing for sensitive documents.

Text editing preserves document appearance. The editor detects fonts in the uploaded PDF and applies them to modified text, which avoids the common issue of font substitution after editing .

Web and desktop options serve different needs. Sejda Web processes files on its servers and deletes them after a period, while Sejda Desktop runs offline and keeps files on the local machine .

Form and signature tools cover common document needs. Users can fill interactive fields, add typed or drawn signatures, and apply text anywhere on a page when form fields are absent .

Conversion extends beyond PDF output. Documents can be converted to editable Office formats or extracted as images, and other file types can be turned into PDFs .

Workflows automate repetitive tasks. Users can chain operations such as merge, compress, watermark, and password protection into a single process for batches of documents .

The free tier includes limits. Online access allows three tasks per hour with a 50MB file size cap, while the desktop free version allows three tasks per day with additional page and OCR limits .
